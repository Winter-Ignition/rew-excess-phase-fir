# 算法及验收

实测复响应的幅度经实倒谱得到最小相位参考，复比为剩余响应。默认 Gaussian 对数频率平滑 FWHM 1/6 倍频程。去传播延迟同时考虑实测峰和最小相位参考峰规约；“最小相位系统 + 纯延迟”应近零剩余相位。峰对齐不等于左右真实播放延迟配对。

检查较短尾窗和加倍 FFT 的影响；加倍 FFT 不能证明 FRD 带外延伸正确。重建 IR 不能认证底噪/削波。原生 IR 的噪声估计亦不能覆盖所有谐波和时钟漂移。

将剩余响应变为复数单位矢量，在对数频率上平滑实部和虚部，再在可信区展开相位。不直接平均 ±180° 显示角，也不平均含窄带整圈跳变的展开角。矢量模长低表示局部方向不一致，此处降低权重、断线灰显。不同宽度在复平面连续混合，避免将候选之间的整数圈差混成斜坡。窄带真实旋转可能被平滑减弱，所以报告定义为该平滑规约下的目标，不声称原始物理群延时消失。

预测曲线先把实际 FIR 的剩余相位乘回原始复响应，再施加冻结的相同矢量平滑，不能简单把滤波相位加到已平滑角度上，因为此平滑不满足该交换关系。应用后复测也使用同一规约。主图展示连续相位，±180° 显示仅用于辅助诊断；整数圈偏移和局部换圈不应改变结果。

各声道独立尝试多个二阶全通项、零/一/二阶低频参考失配及小的线性时间规约项。已知分频点作为起点；未知搜索 0–3 项。交错频点留出误差加复杂度代价选择模型，不声称精确电路识别。误差较大时用一倍频程平滑残差作宽带退路并标记。时间规约项不作为播放延迟；移动过 IR 的单点测量不能唯一分离真实单元偏移与参考失配。

## 统一正则化反演与多尺度分解

用户声明的最低不失真频率至 10 kHz 使用同一框架：参数分频模型提供先验，粗尺度对数频率 Gaussian 基底拟合其余慢变相位，系数二阶差分惩罚限制曲率，Huber 型迭代重加权降低窄带异常的影响。默认基底间隔 0.5 倍频程、sigma 0.65 倍频程、惩罚系数 3。宽带基底不受头部移动权重衰减，300 Hz 不是整体校准的退出点。低频边界仅平顺延伸到 DC，不根据带外未知数据反演；高端 8–10 kHz 接回既定高频规则。

从该慢变基底扣除后的快速残差才进入局部群延时修正。头部三个半范围合成半径 r，343/(8r) 为经验性保守估计，不是唯一物理边界或空间实测保证。局部上限取该估计与 300 Hz 中较低者；未知移动范围默认保守取 200 Hz，静止时由 300 Hz 上限约束。必要时还受声道最高可用频率限制。局部基函数在自己的上限前将相位和斜率归零，不保留 300–400 Hz 的独立退出尾巴。

局部目标先去掉缓慢残差，另对平均相位量加惩罚，避免局部项夺走应该由全局基底承担的偏移。FDW 与测量的 1/6 平滑分开：局部相位核做频变时间限制，默认四周期且不超过前时间的 90%，然后恢复严格的局部频率支持范围。

独立项 8–10 kHz 退出。配对差分项 8–10 kHz 接入，以平滑 ±半差值校准，10 kHz 附近最强，到默认 20 kHz 退出；共同高频相位不压到零。

固定点数实 FIR 加窗及幅度投影。非平凡有限 FIR 不是数学精确全通；默认实际误差 ≤0.03 dB。联合比较慢变基底的正则化强度/幅度和局部深度，以宽带平滑相位误差、低频群延时 RMS/峰值和实际提前能量选择。慢变残差基底的 DC 与高端均为零，允许安全减弱；不能直接用小数缩放含整数圈的参数全通模型。实际 RMS/峰值不得明显恶化，局部项在自身上限之外要通过泄漏检查。FFT 加密不能增加固定 FIR 的时间自由度。

独立读取最终 float32 WAV，检查格式、采样率、点数、映射和摘要。加密 FFT 配合直接 DTFT 抽查。预测剩余相位扣除 FIR 幅度误差对应的最小相位。局部带外影响相对“同一正则化宽带基底 + 高频配对、无局部项”的实际基线核计算，检查起点为每声道实际局部上限；不要求完整滤波在 300/400 Hz 以上零相位。还检查局部退出后的额外群延时，不能只看核心区 RMS。

报告提前 0/1/2/5/10/20 ms 能量及绝对峰值；验收提前 1 ms 总量和基线增量。窄带时间图有分析窗固有展宽，不能将它误称为真实前振铃。能量预算不是不可听证明。共同衰减不能消除时间结构问题。

10 kHz 以上实际双侧校准的平均相位应近零，容许有限 FIR 误差，先去公共参考延迟。单侧无此项。真实物理延迟、极性、路由在系统里另行核实。固定平滑与同轴比较，展示全部峰值，明确区分预测和复测。

低频候选也包含正向二阶全通，用于未知低频/窄带单侧系统；不能将所有低频结构强行解释成倒相箱参考失配。仅有剩余相位的输入直接采用其连续相位；原始测量先作自洽最小相位分解，再对剩余相位默认 1/6 平滑，避免分别平滑幅相后人为制造剩余相位。宽带拟合用未平滑相位的圆周残差，防止窄带完整旋转经平滑后冒充宽带失配；局部群延时和前后比较使用冻结的连续平滑相位。真实原生 IR 优先于频带有限的频响重建。
